# Защита существующей логики

Размеры и занимаемая объектами площадь определяются только в `src/construction/constructionRules.ts`. Человекочитаемая версия этих правил находится в `CONSTRUCTION_RULES.md`. Нельзя дублировать числовые размеры объектов внутри компонентов 2D, 3D или команд строительства.

Любое новое поведение конструктора должно добавляться через отдельную модель или чистую функцию, а не напрямую смешиваться с обработчиками `House3D.tsx`.

## Обязательные уровни проверки

1. **Модель дома** — клетки, стены, проёмы, лестницы и этажи проверяются в `constructionModel` и `constructionCommands`.
2. **Команды** — добавление, удаление, перенос, поворот, дублирование и изменение материала не меняют состояние при невалидной операции.
3. **Выбор объектов** — одиночный и множественный выбор не смешивают разные виды объектов.
4. **Взаимодействия** — hover, click, Alt, Shift, drag threshold и приоритет выбранного объекта проверяются чистыми функциями из `constructionInteraction.ts`.
5. **Синхронизация** — 2D и 3D используют одну модель и одни команды, без параллельной бизнес-логики.
6. **Сборка** — TypeScript обязан собираться без ошибок.

## Инварианты интерфейса

- Обычный клик не перемещает объект.
- Drag начинается только после порога движения курсора.
- Во время drag hover других объектов отключён.
- Hover стены есть только у свободного сегмента; сегмент с проёмом не подсвечивает стену.
- Широкий проём занимает два сегмента и обрабатывается как один объект.
- `Alt + клик` по широкому проёму выбирает все стены под ним.
- Стена перемещается, поворачивается и дублируется вместе с проёмами.
- Невалидная операция не изменяет модель и показывает понятное сообщение.
- 2D и 3D применяют одинаковые команды к одной модели.

## Перед завершением каждой задачи

```bash
npm run check
```

Новое исправление считается завершённым только после добавления регрессионного теста для найденного бага и успешного выполнения всей команды.

## Границы 3D-модулей

- `three/House3D.tsx` связывает интерфейс и сцену, но не хранит повторно используемые правила.
- `three/useConstructionSelection.ts` отвечает за выбор объектов и получение выбранных сущностей из модели.
- `three/constructionTransforms.ts` содержит чистые операции поворота и расчёта перемещения placeholder.
- `three/constructionVisuals.ts` является единым источником цветов hover, selection и невалидного размещения.
- `three/ConstructionMeshes.tsx` содержит геометрию фундамента, стен, проёмов, лестниц и крыши.

Изменение одного слоя сопровождается тестом его публичного поведения. Новые правила размещения остаются в `construction/`, а не переносятся в React-компоненты или геометрию сцены.
