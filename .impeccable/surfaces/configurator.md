# House configurator direction

## Mode

Operate

## World

A calm, comprehensible constructor for a future home. It borrows the precision of an architect's model table without exposing customers to CAD software. Warm mineral surfaces, graphite structure and restrained terracotta accents express domestic warmth and engineering credibility.

## First viewport

The product opens with four plain-language decisions and a live conceptual house preview. The user never meets an empty canvas. Each answer changes the visible house summary, and the primary action promises a result rather than a setup task.

## Workspace

One active decision group sits beside the large model. A narrow summary keeps only area, preliminary price range, region and price date visible. Detailed quantities and assumptions are opened intentionally instead of competing with the model.

## Signature interaction

Changing a supported parameter visibly rebuilds the house and explains the consequence in one sentence, such as `+8 m² · ориентир +0,7–0,9 млн ₽`. The user can undo the change.

## Mobile

Parameters, model and calculation become three sequential views. Controls remain in the lower thumb zone, state is preserved, and 3D has a text equivalent.

## Trust

Cost is always a preliminary range with region, date and included or excluded assumptions. The interface consistently labels the result as a concept rather than construction documentation.
