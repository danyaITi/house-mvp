# Домовид

MVP браузерного конструктора частного дома. Позволяет собрать концепцию дома в 3D, посмотреть план этажей и получить предварительную оценку стоимости строительства.

## Возможности

- Строительство пола, стен, дверных и оконных проёмов, установка окон, дверей, лестниц и крыши.
- Выбор, перенос, поворот и дублирование объектов, отмена и повтор действий.
- Несколько этажей и просмотр дома с улицы.
- Синхронизированный 2D-план для просмотра и смета материалов и работ.

Проект сохраняется в браузере через `localStorage`. Смета ориентировочная и не заменяет строительный проект.

## Запуск

Нужны Node.js 22 версии не ниже 22.13 или Node.js 24 и npm. Выполните команды в корне проекта:

```bash
npm ci
npm run dev
```

Откройте [localhost:5173](http://localhost:5173/). Если порт занят, Vite покажет другой адрес в терминале. Для локального запуска ключи API и файл `.env` не нужны.

Начните с выбора фундамента в каталоге объектов. Строительство выполняется в 3D; вкладка «План» предназначена для просмотра.

## Проверки и сборка

```bash
npm run check    # ESLint, Prettier, тесты и сборка
npm test         # Только тесты
npm run build   # Сборка в dist/
npm run preview # Просмотр сборки
```

## Технологии

React, TypeScript, Three.js / React Three Fiber, Vite и CSS Modules. Тесты — Vitest и Testing Library. Исходники находятся в `src/`: компоненты — в `components/`, расчёты — в `domain/`, строительная логика — в `construction/`, 3D-сцена — в `three/`.
