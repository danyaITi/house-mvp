# Домовид

Веб-приложение для создания концепции частного дома в 3D.
Позволяет посмотреть план этажей и получить предварительную оценку стоимости строительства.

## Возможности

- Строительство фундамента, стен, дверных и оконных проёмов, установка окон, дверей, лестниц и крыши.
- Одиночный и групповой выбор, перенос, поворот и дублирование объектов.
- Отмена и повтор действий.
- Несколько этажей и режим просмотра дома с улицы.
- Синхронизированный 2D-план для просмотра и предварительная смета материалов и работ.
- Сохранение проекта в `localStorage` между посещениями в том же браузере.

Смета ориентировочная и не заменяет строительный проект.

## Стек

React, TypeScript, Vite, Three.js, React Three Fiber, Drei и CSS Modules. Проверки: ESLint, Prettier, Vitest и React Testing Library.

## Запуск

Понадобятся Node.js 22 (от 22.13) или Node.js 24 и npm. API-ключи и файл `.env` не требуются.

В корне проекта выполните:

```bash
npm ci
npm run dev
```

Откройте адрес, который Vite выведет в терминале — обычно [localhost:5173](http://localhost:5173/).

Начните с выбора фундамента в каталоге объектов. Строительство выполняется в 3D; вкладка «План» предназначена для просмотра.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Сервер разработки |
| `npm run build` | Проверка TypeScript и сборка в `dist/` |
| `npm run preview` | Локальный просмотр готовой сборки |
| `npm run lint` | Проверка кода ESLint |
| `npm test` | Запуск тестов |
| `npm run test:watch` | Тесты в режиме наблюдения |
| `npm run format` | Форматирование кода Prettier |
| `npm run check` | ESLint, проверка форматирования, тесты и сборка |
